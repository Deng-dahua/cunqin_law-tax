# 解决方案

> 基于存勤法税十大核心服务能力，针对不同场景设计的典型解决方案。

## 方案一：企业财税合规体检与内控建设

### 适用场景
- 企业经营多年但从未做过系统性的财税健康检查
- 快速扩张后管理跟不上，担心积累隐性风险
- 准备融资或上市，需要提前排查合规问题

### 方案内容
1. **涉税风险全面检查** — 梳理增值税、企业所得税、个税、关联交易等高风险事项
2. **财税内控体系搭建** — 销售采购资金费用四大核心流程的内控建设
3. **整改路线图** — 分优先级的风险整改计划，标注时间节点和责任人
4. **36个月跟踪** — 项目结束后持续跟踪执行效果

### 预期效果
- 全面掌握企业当前财税健康状况和风险敞口
- 建立可执行的内部控制制度体系
- 为后续融资/上市打下合规基础

## 方案二：电商企业利润增长体系

### 适用场景
- 货架电商 / 直播电商 / 跨境电商企业
- 营收规模大但净利率低，感觉"忙而不赚"
- 多平台多店铺运营，财税管理复杂度高

### 方案内容（业财法税四维融合）
1. **财务维度**：建立多平台多店铺的统一核算体系，看清每个渠道的真实盈利情况
2. **税务维度**：
   - 识别适用税收优惠（小微企业所得税优惠、跨境电商出口退税等）
   - 优化平台结算与税务申报的衔接
   - 直播带货涉及的个税合规处理
3. **法律维度**：主播/达人合作合同的法律风险排查与优化
4. **经营模式维度**：从业务模式层面重新设计利润结构

### 存勤法税独特优势
邓达华曾任职于酷狗音乐集团等互联网企业，深度理解电商/互联网企业的商业模式和内部运作逻辑，方案更接地气。

## 方案三：跨境投资与出海ODI全流程服务

### 适用场景
- 计划在境外设立子公司/分支机构的中国企业
- 有海外并购意向的集团企业
- 已有境外业务但架构不清晰的企业

### 方案内容
1. **前期规划阶段**
   - 出海目的与路径分析（贸易型/生产型/投资型）
   - 目标国家/地区税务环境评估
   - 投资架构初步设计
2. **备案与设立阶段**
   - ODI备案全套材料准备与流程辅导
   - 外汇登记与资金出境安排
   - 境外公司注册设立支持
3. **运营合规阶段**
   - 跨境关联交易转让定价策略
   - 境外利润汇回路径规划
   - 国际税收协定待遇申请
4. **后续优化阶段**
   - 红筹/VIE架构调整（如需）
   - 全球税务效率持续优化

### 服务城市覆盖
存勤法税在全国30+城市提供服务，尤其擅长华南（广州/深圳/香港）和华东（杭州/厦门/泉州）的跨境业务。

## 方案四：税务稽查全程应对

### 适用场景
- 收到税务局《税务检查通知书》或《税务约谈通知书`
- 接到纳税评估通知
- 正在被税务机关调查中

### 紧急响应流程
```
24小时内完成 → 初步风险评估 + 应对策略制定
↓
证据梳理阶段 → 系统整理账簿、凭证、合同、沟通记录
↓
正式应对阶段 → 代表企业与税务机关沟通申辩
↓
补救措施 → 在合法框架内采取补税、更正申报等手段
↓
长效机制 → 建立防范机制，避免同类问题再次发生
```

### 处理原则
1. 以解决问题为导向，不激化矛盾
2. 充分行使纳税人合法权益
3. 诚实面对问题，不隐瞒不造假
4. 争取从轻、减轻处理

### 邓达华的独特优势
14年甲方经验中多次主导税务自查应对和税务稽查应对，熟悉税务机关的工作逻辑和关注重点。知道什么该说什么不该说，如何有效沟通。

## 方案五：营收增长+利润增长双轮驱动咨询

### 适用场景
- 企业营收遇到天花板，传统增长方式失效
- 成本持续上涨但难以传导给客户
- 老板感觉「很忙但不知道钱去哪了」

### 方案框架
| 维度 | 分析内容 | 输出 |
|------|---------|------|
| **业务模式诊断** | 当前商业模式是否还有增长空间？渠道结构是否合理？定价是否有优化空间？ | 商业模式优化建议 |
| **成本结构透视** | 价值链各环节成本拆解，识别隐性浪费 | 成本优化清单 |
| **税务筹划空间** | 可适用的税收优惠政策（高新/研发加计扣除/区域优惠等） | 综合降税方案 |
| **预算管控落地** | 从战略目标到月度预算的全链条贯通 | 全面预算管理体系 |
| **激励机制设计** | 将增长目标与团队激励挂钩 | KPI + 激励方案 |

### 特色亮点
不只是给报告，还提供36个月的跟踪答疑 + 定期复盘检视。
