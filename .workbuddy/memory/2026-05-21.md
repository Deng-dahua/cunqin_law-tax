## 按德勤风格重新设计存勤法税官网

### 背景
- 用户要求参考德勤中国官网（https://www.deloitte.com/cn/zh.html）重新设计存勤法税官网
- 德勤官网特点：专业稳重、深蓝配色、大量留白、卡片式布局、清晰的视觉层次

### 遇到的问题
1. **Hexo `source/index.html` 生成问题**：
   - 第一次尝试：写了 YAML front-matter（`layout: false`），Hexo 把文件当作文章处理，用 Fluid 主题渲染，导致生成的 `public/index.html` 仍然是 Fluid 主题的文章列表页面
   - 第二次尝试：去掉 front-matter，直接写纯 HTML，Hexo 正确原样复制到 `public/index.html`
   - **结论**：Hexo 对 `source/` 下的 HTML 文件，有 front-matter 就渲染，没有就原样复制

2. **部署后访问还是旧版本**：
   - 原因：CDN/浏览器缓存
   - 解决：清除浏览器缓存（Ctrl+Shift+R）后刷新

### 最终方案
- `source/index.html`：纯 HTML 文件，无 front-matter，包含完整的德勤风格页面（导航栏、Hero 首屏、数据条、服务卡片、关于区块、客户案例、文章列表、联系我们、页脚）
- `source/css/custom.css`：德勤风格自定义 CSS（配色、布局、响应式）
- 配色方案：
  - 主色：深蓝 `#003f6c`（德勤蓝）
  - 点缀色：青绿 `#00a19c`
  - 辅助色：浅灰 `#f8f9fa`、深灰 `#333`、`#666`

## 内页全面重写为德勤风格独立HTML

### 用户反馈
用户发现所有内页仍然是旧版Fluid主题风格，只有首页是德勤风格：
- 关于我们：灰色banner、Fluid猫头像、旧导航栏
- 核心服务：灰色banner、文档式排版
- 客户案例：同上
- 法税洞察：**404页面不存在**
- 联系我们：仍在显示电子邮箱

### 解决方案
将所有内页从 `.md` 文件改为独立的 `.html` 文件（同首页策略）：

| 页面 | 旧文件 | 新文件 |
|------|--------|--------|
| 关于我们 | `source/about/index.md` | `source/about/index.html` |
| 核心服务 | `source/services/index.md` | `source/services/index.html` |
| 客户案例 | `source/cases/index.md` | `source/cases/index.html` |
| 法税洞察 | (不存在) | `source/archives/index.html` |
| 联系我们 | `source/contact/index.md` | `source/contact/index.html` |

### 新内页设计特点
- **统一导航栏**：Logo + 存勤法税 + 6个菜单项（与首页一致）
- **统一页脚**：品牌介绍/快速链接/服务项目/联系方式（无邮箱）
- **统一配色**：深蓝 `#003f6c` + 青绿 `#00a19c`
- **统一Hero区域**：深蓝渐变背景 + 页面标题 + 副标题
- **响应式设计**：适配手机/平板/电脑

### 各页面内容
1. **关于我们**：公司介绍 → 创始人（照片+履历）→ 核心优势（2卡片）→ 核心价值观（3图标）→ 数据条（18年/30+城市/14行业/80+企业）
2. **核心服务**：10张服务卡片（编号+标题+描述+标签），2列布局
3. **客户案例**：5个案例卡片（图标+标题+行业/规模/时长+痛点+方案+成果），底部行业覆盖网格
4. **法税洞察**：8篇文章列表（日期+标题+摘要+标签），按时间倒序排列
5. **联系我们**：联系方式（电话/时间/地址）+ 微信二维码 + 服务响应（3卡片）+ 免责声明

### 技术要点
- `_config.yml` 更新 `skip_render` 包含所有内页HTML文件
- 所有路径使用相对路径（`../images/...`、`../about/` 等）
- 删除旧 `.md` 文件，避免Fluid主题渲染冲突
