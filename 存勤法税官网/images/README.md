# images 文件夹

此文件夹存放网站使用的图片文件。

## 必须包含的文件

| 文件名 | 说明 | 必需 |
|--------|------|------|
| `logo.png` | 公司Logo | ✅ 是 |
| `wechat-qrcode.jpg` | 微信二维码 | ✅ 是 |
| `founder.jpg` | 创始人照片（about页面使用） | 建议 |

## 图片要求

### logo.png
- 格式：PNG（透明背景）
- 尺寸：200x200 像素
- 文件大小：< 100KB

### wechat-qrcode.jpg
- 格式：JPG
- 尺寸：300x300 像素
- 文件大小：< 200KB

### founder.jpg
- 格式：JPG
- 尺寸：400x400 像素
- 建议：专业商务照片

## 注意事项

- 所有图片请使用有意义的文件名（英文或拼音）
- 确保图片压缩优化，减少加载时间
- 建议使用 WebP 格式以提升性能
