## 图片优化建议

1. **压缩图片**：使用TinyPNG、ImageOptim等工具压缩图片，减小文件大小
2. **WebP格式**：考虑提供WebP格式图片，现代浏览器支持更好
3. **响应式图片**：为移动设备准备小尺寸图片

## 获取图片的方式

### 1. Logo设计
- 使用Logo设计工具：Canva、LogoMaker、或找专业设计师
- 确保Logo在不同背景下都清晰可见

### 2. 创始人照片
- 使用专业相机拍摄
- 选择简洁背景
- 着装正式、表情自然

### 3. 背景图片
- 使用免费图库：Unsplash、Pexels、Pixabay
- 确保图片与财税、法律主题相关
- 注意图片版权

### 4. 微信二维码
- 登录微信公共平台获取
- 确保二维码清晰可扫描

## 图片替换步骤

1. 准备好所有图片文件
2. 将图片文件复制到 `source/images/` 目录下
3. 确保文件名与上方表格中的文件名一致
4. 提交到GitHub仓库
5. GitHub Actions会自动部署更新后的网站

## 图片SEO优化

1. **文件名**：使用描述性文件名，如 `founder-deng-dahua.jpg` 而非 `IMG_001.jpg`
2. **Alt标签**：在HTML中为所有图片添加alt属性
3. **标题属性**：为重要图片添加title属性
4. **图片大小**：确保图片尺寸与实际显示尺寸匹配

## 注意事项

- 确保拥有所有图片的版权或使用权
- 避免使用带水印的图片
- 图片文件大小不宜过大（建议每张图片<500KB）
- 使用工具压缩图片以提高网站加载速度
