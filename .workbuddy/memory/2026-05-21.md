## 按德勤风格重新设计存勤法税官网

### 背景
- 用户要求参考德勤中国官网（https://www.deloitte.com/cn/zh.html）重新设计存勤法税官网
- 德勤官网特点：专业稳重、深蓝配色、大量留白、卡片式布局、清晰的视觉层次

### 遇到的问题
1. **Hexo `source/index.html` 生成问题**：
   - 第一次尝试：写了 YAML front-matter（`layout: false`），Hexo 把文件当作文章处理，用 Fluid 主题渲染，导致生成的 `public/index.html` 仍然是 Fluid 主题的文章列表页面
   - 第二次尝试：去掉 front-matter，直接写纯 HTML，Hexo 正确原样复制到 `public/index.html`
   - **结论**：Hexo 对 `source/` 下的 HTML 文件，有 front-matter 就渲染，没有就原样复制

2. **部署后访问还是旧版本**：
   - 原因：CDN/浏览器缓存
   - 解决：清除浏览器缓存（Ctrl+Shift+R）后刷新

### 最终方案
- `source/index.html`：纯 HTML 文件，无 front-matter，包含完整的德勤风格页面（导航栏、Hero 首屏、数据条、服务卡片、关于区块、客户案例、文章列表、联系我们、页脚）
- `source/css/custom.css`：德勤风格自定义 CSS（配色、布局、响应式）
- 配色方案：
  - 主色：深蓝 `#003f6c`（德勤蓝）
  - 点缀色：青绿 `#00a19c`
  - 辅助色：浅灰 `#f8f9fa`、深灰 `#333`、`#666`
